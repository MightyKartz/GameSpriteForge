# Forge CLI v0.7.3

Forge remains free under MIT. Forge PRO is a separate private project; existing
Forge commands, examples and licenses remain available.

## Changes

- Updated the embedded offline guide for video-derived character animation:
  inspect the entire clip, prefer a later complete continuous cycle when the
  beginning is unusable, preserve original timing, and review actual previews.
- Added the accepted three-view courier example and a side-running Godot turn
  test. A mirrored side view supports left/right; this is not a claim of four
  generated movement directions or automatic gait detection.
- Clarified the free/PRO boundary. Video generation remains external; local
  Forge processing prepares and delivers supplied assets.

## Compatibility and verification

No processing API or Pack format changed since v0.7.2. Existing consumer binary
pins and separately installed skills are not automatically upgraded. Run the
selected binary's `forge guide` for its bundled instructions.

The tag release workflow builds and tests macOS Apple Silicon and experimental
Windows x64 packages before publishing both together. Packages remain unsigned;
macOS is not notarized. Runtime checks do not replace artistic review.
