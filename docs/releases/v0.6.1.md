# Forge CLI v0.6.1

Forge v0.6.1 keeps the v0.6.0 Godot 4.6.x/4.7.x, asset-library, static, layered,
audio and acceptance capabilities while simplifying the Windows release download.

## Windows single-download installer

Windows users now download one `forge-windows-installer.zip`. It contains the
verified portable package, its SHA-256 file, the installer and the shared support
script. Extract it and run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-windows.ps1
```

The installer discovers and verifies the bundled archive automatically. Existing
installations, payloads and launcher backups remain protected; PATH is not
changed. The underlying package still includes FFmpeg/FFprobe, source archives
and license notices. Audit materials such as the full package checksum, SBOM and
paired verification report remain available separately.

## Verified behavior

The Windows package workflow packages the single-download bundle, extracts it,
and installs through the included installer. It also verifies the original
archive path, reinstall idempotence, checksum/traversal/payload tamper rejection,
junction refusal, modified-launcher preservation, upgrade backups, bundled
FFmpeg media processing, PowerShell 5.1 compatibility, static/layered preview,
library portability and native Godot playback.

The release workflow verifies that the single-download bundle contains exactly
the tested package, checksum and installer before publishing. macOS and Windows
packages remain unsigned; the macOS package is not notarized.
