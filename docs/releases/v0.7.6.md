# Forge CLI v0.7.6

Forge remains free under MIT; Forge PRO is maintained separately.

## Changes

- Embedded offline guidance adds an explicit four-frame, non-looping effect
  example with shared coordinates, canvas/pivot and per-frame durations.
- Scene audio examples distinguish battle/camp loops from one-shot victory audio,
  measured final levels from estimates and native PCM16 delivery from source files.
- Static artwork guidance checks complete weapon silhouettes and game display
  scale before batch production; padding cannot recover clipped artwork.
- Generation, Forge processing, PRO orchestration and consumer review retain
  separate identities and evidence. No model is bundled by these changes.

Read `forge guide animation`, `forge guide audio` and `forge guide static`.
The guidance update is [PR #87](https://github.com/MightyKartz/GameSpriteForge/pull/87).
[Source/example QA](../qa/asset-production-lessons-2026-10-07.md) records exact
processing and macOS Godot checks separately from artistic/listening approval.

No processing API or Pack format changed since v0.7.5. Existing consumer binary
pins and installed skills are not automatically upgraded. After a verified CLI
upgrade, check managed skills with `forge skill check --project .`; an explicit
`forge skill install` updates the managed bundle.

The tag workflow verifies paired macOS Apple Silicon and experimental Windows x64
packages, installed public launchers, upgrades, bundled helpers and native Godot
before publication. Packages are unsigned; macOS is not notarized. Technical
checks do not establish artistic quality, listening, licensing or device approval.
