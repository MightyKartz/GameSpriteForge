# Forge CLI v0.6.4

Forge v0.6.4 makes local asset delivery easier to diagnose and release downloads
easier to choose. It incorporates production feedback from the Survival project.

## Local delivery reliability

- `forge storage check --path DIR --json` probes an existing directory for the
  filesystem operations required by delivery: exclusive publication, overwrite
  protection, replacement, hard links and file locks. Check `supported`, not just
  `ok`; unsupported storage such as an incompatible ExFAT volume is diagnosed
  before production without weakening delivery guarantees.
- `forge guide local-delivery-example` provides an offline Python workflow that
  pins the executable SHA-256, requires reviewed source locks, checks storage and
  capabilities, prepares a Pack, and installs it directly into Godot. It retains
  the Pack, receipts, progress and recovery evidence with zero Provider requests.
- The example submits the validated request snapshot through stdin, preserves
  relative source paths and decodes CLI output as UTF-8 on both platforms.
- Godot toolchain schema validation now agrees with runtime support for 4.6 and
  4.7, including patchless version strings. Mixed `preserve_source` static
  canvases report the affected item groups; installation failures identify the
  phase and explain where to find logs and recovery instructions.

## Simpler downloads

Choose the recommended installer for your system from the download table above.
Uploaded release assets are reduced from 14 to 8. Existing installer, portable
archive and checksum filenames remain compatible with automated downloads.

`forge-source-and-notices.zip` consolidates pinned FFmpeg/zlib source archives,
licenses, build recipes, native build identities, a macOS-target Rust SBOM and
the paired package verification report. Its internal SHA-256 manifest covers
every included file. It is optional for installation. The Windows installer ZIP
already contains the complete portable package and checksum.

See the [download guide](downloads.md) and
[Windows installation guide](windows-portable.md). Historical releases retain
their original attachments.

## Verification and scope

The delivery changes passed PR #56's nine CI checks, including native macOS and
Windows with Godot 4.6.3 and 4.7.2, Windows package installation/upgrade and
bidirectional resource exchange. The download assembler passed its regression
suite on macOS, Windows and Linux, and was rehearsed against the actual v0.6.3
packages with an isolated macOS installation.

See [delivery verification](../qa/survival-delivery-implementation-2026-09-21.md),
[review fixes](../qa/pr56-review-2026-09-21.md) and
[download verification](../qa/release-downloads-2026-09-21.md). The versioned
v0.6.4 packages must separately pass the paired native release workflow before
publication; source and packaging tests do not replace those installed checks.

macOS Apple Silicon and experimental Windows x64 remain the supported release
targets. Install Godot 4.6.x or 4.7.x separately for native delivery. Packages are
unsigned and macOS is not notarized. Updating Forge does not update a game's
toolchain lock or a separately installed Codex skill. Technical acceptance does
not establish artwork quality or license approval.

- 新增 `forge storage check --path DIR --json`，检查现有目录是否支持交付所需的
  独占发布、防覆盖、替换、硬链接和文件锁。应检查 `supported` 字段，不能仅看 `ok`；
  对不满足要求的 ExFAT 等存储提前给出诊断，不降低交付保证。
- `forge guide local-delivery-example` 提供离线 Python 示例：固定 CLI 的 SHA-256，
  要求已审核源文件锁，预检存储与能力，加工后直接安装到 Godot，并保留 Pack、回执、
  进度和恢复证据。整个流程不调用 Provider。
- 示例将已经验证的请求快照通过 stdin 提交，保留相对路径，跨平台统一使用 UTF-8。
  Godot 工具链 schema 与 4.6 / 4.7 运行时支持对齐；静态素材画布不一致时列出相关分组，
  安装失败时明确失败阶段和日志、恢复说明的位置。
- 发布附件从 14 个减少为 8 个，推荐下载按系统置顶。安装脚本、便携包和校验文件的
  既有名称保持兼容；Windows 用户只需下载完整安装 ZIP。源码、许可证、构建说明、
  macOS 目标的 Rust SBOM 和双平台包验证报告集中在可选的
  `forge-source-and-notices.zip`，其内含逐文件 SHA-256 清单。

交付改进已通过 PR #56 的 9 项 CI，覆盖 macOS/Windows、Godot 4.6.3 / 4.7.2、
Windows 安装升级和双向资源交换。附件整合测试已在 macOS、Windows、Linux 通过，
并使用真实 v0.6.3 发布文件完成整合及隔离 macOS 安装演练。v0.6.4 版本化安装包另经
双平台原生发布流程验证后才会发布。历史发布附件保持原样；游戏工具链锁和已安装的
Codex skill 不会自动升级。平台范围与签名状态不变，技术验收不代表美术质量或许可审批。
