# Forge CLI v0.7.5

Forge remains free under MIT; Forge PRO is maintained separately.

## Changes

- Added embedded offline guidance for Godot UI artwork: preserve rectangular
  sources and nine-patch coordinates, separate independent visual layers, keep
  native text and focus states, and bind textures through game-owned controls.
- Clarified the boundary between free texture preparation/delivery and Forge PRO
  beta.4's editable UI/title authoring templates. UI navigation remains game logic.
- Included the bilingual creator-verification homepage link already on main.

No processing API or Pack format changed since v0.7.4. Existing consumer binary
pins and installed skills are not automatically upgraded. Read the selected
executable's `forge guide static`.

The tag workflow checks macOS Apple Silicon and experimental Windows x64 builds,
installed public launchers, upgrades, bundled helpers and native Godot delivery
before publishing both packages together. Packages are unsigned; macOS is not
notarized. Technical checks do not establish visual quality or licensing approval.
