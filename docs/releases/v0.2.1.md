# Forge CLI v0.2.1

This release improves the default CLI's delivery of existing character animation
to Godot. The platform remains **macOS Apple Silicon**, with Godot **4.6.x**
installed separately.

## Changes

- Preserve nonuniform per-frame animation durations in Pack validation and native
  Godot SpriteFrames resources.
- Carry pixel snapping and texture filtering settings into Godot delivery.
- Retain human-review provenance and validate animation review metadata.
- Include Rust 1.98 compatibility fixes and stronger release artifact checks.
- Document an experimental, zero-generation directional reuse workflow in the
  source tree, with source-integrity checks and Godot review templates.

## Installation

Download `forge-installer.sh` from this release, then install the stable version:

```bash
FORGE_VERSION=v0.2.1 sh forge-installer.sh
```

To test the earlier candidate, select `FORGE_VERSION=v0.2.1-rc.1` explicitly;
prereleases do not replace the stable installer default. The installer validates
archive and payload SHA-256 manifests and preserves previous version directories
during upgrades. The archive bundles `forge`, `ffmpeg`, and `ffprobe`; the release
also includes an SBOM, GitHub artifact attestation, and corresponding FFmpeg source.
The binaries remain **unsigned and not notarized**.

## Scope and experimental reuse

This binary uses the default Cargo features (`default = []`). Subject/Character V2,
world assets, and game-art manifest workflows remain optional source-build features.
Retained desktop/MCP code and archived development work are outside this release.

The three-direction reuse helper is **source-only**, not installed by the CLI
installer. Download this tag's source archive or check out the same tag, then run
`python3 scripts/character/prepare_directional_reuse.py --help`. Keep the adjacent
`scripts/character/godot` templates. Execution requires Python 3.9+, Pillow, this
release's CLI, Godot 4.6.x, and the expected approved right/down/up recovery Packs
and geometry evidence. Source media is not bundled. See
[the workflow](https://github.com/MightyKartz/GameSpriteForge/blob/main/docs/architecture/forge-existing-animation-reuse-plan.md).

Each output candidate requires its own visual review. This release does not
generate missing left-facing or idle animations and does not promote the previously
reviewed candidate into production assets. Automated checks use fixtures and do
not establish real-provider generation quality.
