# Forge CLI v0.3.2

Codex can now read Forge's complete usage guide directly from the CLI. Install
Forge, open your game project and ask Codex to read the embedded guide before
preparing your assets. No skill installation or Forge source checkout is needed.

## Read the guide

```bash
forge guide
forge guide static
forge guide static-example
```

The default guide explains executable selection and routes to local PNG
processing, optional Provider generation and experimental animation. Each
reference and request example is available by topic or exact bundle path. Plain
output preserves the original file; `--json` includes its path, SHA-256, resource
list and the bundle's CLI/build identity. Reads are offline and do not create
Plans, Jobs or installed files, access Provider credentials, or change Codex
configuration.

Keep using a game's verified Forge executable for both its guide and asset
commands. Upgrading that executable brings the matching guide. Older pinned
versions remain usable: v0.3.1 can expose its bundle through `skill show --json`,
while v0.3.0 needs matching file documentation. Reading instructions does not
require changing a game's toolchain lock or existing asset receipts.

## Optional Codex skill discovery

`forge skill install --project .` and `forge skill install --user` remain
available when you want Codex to discover `forge-use` by name. Installing only
the CLI does not register a Codex skill. The guide and installed skill use the
same maintained content source.

Installed skills still require an explicit update after a CLI upgrade. Identical
installs remain unchanged; updates to unmodified Forge-managed content retain a
backup. Forge preserves modified files, unrecognized installations and symlink
targets instead of overwriting them.

See [Codex usage and optional setup](https://github.com/MightyKartz/GameSpriteForge/blob/v0.3.2/docs/automation/codex-skill.md)
for resource names, installation scopes and update behavior.

## Install and compatibility

Download `forge-installer.sh` from this release, then run:

```bash
FORGE_VERSION=v0.3.2 sh forge-installer.sh
forge --version
forge doctor --json
forge guide
```

The regular installer selects the latest stable release and retains older CLI
version directories. `doctor` adds `embedded_usage_guide` to the capability list.
Existing local PNG processing, Pack and Godot contracts are unchanged.

This release supports **macOS Apple Silicon**. Install **Godot 4.6.x** separately
for engine delivery. New artwork comes from a separate Codex image tool or your
preferred image tool; Forge handles the resulting local PNGs. Local preparation
requires no Forge Provider account. Character animation remains in development
and testing; advanced character and world-asset workflows remain source-gated.

Binaries remain unsigned and not notarized. Release assets include checksums,
build identity, SBOM/attestation and the corresponding bundled FFmpeg source.
