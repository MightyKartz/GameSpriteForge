# Forge CLI v0.7.2

**Codex discovery for every install: skill installation now works on Windows.**

v0.7.2 is a focused patch over v0.7.1. `forge skill install` and
`forge skill check` previously rejected Windows scopes with an unimplemented
error, so the documented path to let Codex discover Forge failed for Windows
users. The safe install transaction now runs on macOS, Linux and Windows with
the same contract.

## What changes

- **Windows skill installation:** the atomic no-replace commit uses
  `MoveFileExW` without the replace flag, matching the macOS `renameatx_np` /
  Linux `renameat2` semantics exactly: a target that appears concurrently,
  even an empty directory, is never overwritten. Backups, modification and
  symlink protection are unchanged.
- **Correctness fixes behind the new platform:** manifest identity keys are
  built with portable separators (an installed skill was previously reported
  as modified on Windows), and reported scope paths use the familiar
  drive-letter form rather than verbatim `\\?\` prefixes.
- **Recommended setup is now part of installation:** the README and the
  installer next-step message recommend `forge skill install --project` with
  `.agents/skills/forge-use/` committed into the game repository, so every
  collaborator's Codex discovers Forge without individual setup; `--user`
  remains the personal multi-project option. `forge guide` continues to
  provide the same workflows offline without any installation.

## Compatibility and upgrade

Existing installed skills, backups and manifests are untouched; `skill check`
reports their state exactly as before. The change is confined to the skill
install transaction and its tests; no asset, Pack, catalog or Godot contract
changes. See [downloads](downloads.md) and [Windows installation](windows-portable.md).

## Verification and limitations

Windows skill installation, idempotent updates, backups, modified/unmanaged
preservation and symlink protection run in the Rust suite and in the full
(non-guide-only) CLI acceptance script on Windows CI; unprivileged local
Windows sessions probe and explicitly skip symlink creation while privileged
CI runners exercise it. Workspace clippy runs with `-D warnings`. See the
[release verification record](../qa/release-v0.7.2.md).

macOS Apple Silicon and experimental Windows x64 remain the release targets.
Packages are unsigned and macOS is not notarized. Symlink-protection tests
require a privileged Windows session; all other behavior is identical across
platforms.

**v0.7.2：每次安装都能让 Codex 发现 Forge——skill 安装现已支持 Windows。**

v0.7.1 及更早版本的 `forge skill install` 在 Windows 上直接报错，文档指引对
Windows 用户不可用。本版本在 Windows 上实现同样的安全安装事务：原子提交
使用不带替换标志的 `MoveFileExW`，并发出现的任何目标（包括空目录）都不会
被覆盖；备份、修改与符号链接防护不变。同时修复了 Windows 下清单键的路径
分隔符导致装完即被误判为已修改的问题，以及报告路径带 `\\?\` 前缀的问题。

README 与安装器下一步提示现在推荐项目级安装：把 `.agents/skills/forge-use/`
提交进游戏仓库，团队成员的 Codex 全部自动发现；`--user` 仍是个人跨项目选项。
`forge guide` 继续离线提供同样内容，不安装 skill 也不受影响。

既有已装 skill、备份与清单保持原样；改动仅限 skill 安装事务及其测试。符号
链接防护测试需要 Windows 特权会话，无权限会话显式探测跳过，CI 完整覆盖。
发布平台、签名状态与许可边界不变。
