# Forge CLI v0.7.4

Forge remains free under MIT; Forge PRO is maintained separately.

## Changes

- Updated the embedded offline guide: review multi-threshold transparent bounds,
  distinguish canvas size from gameplay size, and export a new receipt after
  accepted same-ID artwork replacement while retaining the old receipt.
- Added a forest-scene template with separate prop/background requests and Godot
  layout review. The source artwork must be supplied separately.
- Added the Feishu community invitation to both READMEs.

No processing API or Pack format changed since v0.7.3. Existing consumer binary
pins and installed skills are not automatically upgraded. Read the selected
executable's `forge guide`.

The release workflow verifies macOS Apple Silicon and experimental Windows x64
packages, installed launchers, upgrades and native Godot delivery before publishing
both together. Packages are unsigned; macOS is not notarized. Technical checks do
not grant artistic or licensing approval. The static trial's visual review was
performed on macOS; it is not a Windows artwork review.
