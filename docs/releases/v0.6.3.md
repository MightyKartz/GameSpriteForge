# Forge CLI v0.6.3

Forge v0.6.3 improves animation review and sharing. Resource-library previews use
original PNG frames, preserving soft transparency and native frame timing, while
shareable MP4 videos are generated separately from those PNGs.

## Animation previews

- `forge asset preview` plays flat animation/character Packs directly from their
  PNG frames, including existing Packs. Select an animation, pause, step through
  frames, and switch between dark, light and checkerboard backgrounds.
- `forge pack preview --path effect.gsfpack --out preview.mp4` exports one cycle
  as H.264 MP4. Optional animation/background selection and a verified cache are
  available; reports identify source content, encoder and native/encoded timing.
- Compatibility GIFs now clear previous frames and follow native per-frame
  durations. Low-alpha RGB no longer becomes opaque speckles in newly generated
  GIFs. GIF still has limited colors and binary transparency.
- Windows bundles include Media Foundation H.264 encoding with NV12 input.
  Browser-player CSP hashes work with both LF and Windows CRLF line endings.

Existing source PNGs, Packs, catalog revisions, consumer toolchain locks and
delivery receipts are not rewritten. Old stored GIFs remain unchanged; flat
Packs use the new PNG viewer without regeneration. Layered/world/audio Packs
retain their existing viewers.

MP4 has a baked background, uses normal alpha composition and quantizes timing
to 60 fps. It is a sharing preview, not a transparent game asset. GIF remains a
compatibility artifact required by existing Pack formats. Use Godot for engine
blend modes and layered playback; technical checks do not establish art quality.

## Verification and installation

PR #55 passed nine CI checks, including macOS and Windows with Godot **4.6.3 and
4.7.2**, native H.264 encode/probe/decode checks, Windows fresh installation and
historical upgrade, the quality matrix and cross-platform resource exchange.
See [preview verification](../qa/2026-09-19-animation-previews.md) for source
identities and limitations. Versioned release packages are built and checked
separately by the paired macOS/Windows release workflow before publication.

macOS Apple Silicon uses `forge-installer.sh`. Windows x64 users download
`forge-windows-installer.zip`, extract it and run the included installer. The
Windows encoder requires working operating-system Media Foundation support.
Packages are unsigned; macOS is not notarized; Windows remains experimental.
Upgrading the CLI does not automatically change a game's toolchain lock or an
installed Codex skill. Read `forge guide animation` after upgrading.
