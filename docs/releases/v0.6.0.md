# Forge CLI v0.6.0

Forge v0.6.0 adds Godot 4.7 compatibility and pinned version selection to the
existing image, animation, audio, resource-library and project acceptance
workflows. macOS Apple Silicon and experimental Windows x64 packages share this
release.

## Godot 4.6.x and 4.7.x

Builds with `godot_version_selection` accept an existing Godot 4.6.x or 4.7.x
installation. `forge setup godot --download` now defaults to the checksum-pinned
official Godot **4.7.2** standard editor; select the previous release explicitly
with `--version 4.6.3` when a project requires it. `--templates` installs the
matching export templates for the selected engine.

```sh
forge setup godot --path /absolute/path/to/Godot --json
forge setup godot --download --json
forge setup godot --download --version 4.6.3 --templates --json
forge godot lock --project /absolute/game --json
forge godot check --project /absolute/game --json
```

The two engine versions coexist in separate managed directories. A project's
`.forge/toolchain.lock.json` still pins its complete engine version; choosing a
new engine on the machine does not rewrite that lock. `check`, delivery,
verification and export fail on a mismatch until the project explicitly accepts
a verified update with `godot lock --update`.

The v0.5.0 CLI remains limited to Godot 4.6.x and its pinned 4.6.3 download.
Read `forge guide godot-workflow` from the executable being used before relying
on `--version`, because older pinned executables do not gain new options from a
newer source guide.

## Verified behavior

CI covers macOS and Windows against both Godot 4.6.3 and 4.7.2, including native
transaction checks, empty-gate rejection and project acceptance. The paired
macOS/Windows resource exchange remains covered. A separate real generated
monster/effect workflow was installed through the packaged launcher, registered
in the resource library, delivered to Godot 4.7.2, exercised with native
playback controls, and exported to a native macOS application for a bounded
startup check; see [the runtime QA record](../qa/real-assets-godot-47-20260917.md).

This evidence does not replace game-specific visual, listening, license,
performance or device review. Character animation remains experimental. Windows
packages remain experimental; packages are unsigned and the macOS package is not
notarized.

## Install and upgrade

On macOS Apple Silicon, download `forge-installer.sh` from this release and run:

```sh
FORGE_VERSION=v0.6.0 sh forge-installer.sh
forge --version
forge doctor --json
```

On Windows x64, download the ZIP, its `.sha256` file, `install-windows.ps1` and
`windows-package-common.ps1` into one directory:

```powershell
$archive = Join-Path $PWD 'forge-x86_64-pc-windows-msvc.zip'
$expected = (Get-Content -LiteralPath "$archive.sha256").Split(' ')[0]
& .\install-windows.ps1 -Archive $archive -Sha256 $expected
& "$env:LOCALAPPDATA\GameSpriteForge\bin\forge.cmd" doctor --json
```

Packages include FFmpeg/FFprobe and their license/source notices. Existing game
pins, receipts and installed Codex skills are not updated automatically. Verify
an existing project with the new executable before updating its toolchain lock.
