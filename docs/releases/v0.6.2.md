# Forge CLI v0.6.2

Forge v0.6.2 improves local image preparation for generated art and flat-color
source backgrounds. The release keeps the v0.6.1 Windows single-download
installer and the v0.6.0 Godot 4.6.x/4.7.x support.

## Matting and alpha preservation

The guide now recommends a clean transparent RGBA source first. Use
`source inspect` for sprite-sheet grid diagnostics and
`matting:{"mode":"preserve_alpha"}` when the source already carries reviewed
transparency. This path preserves soft glow and edge pixels instead of treating
them as background.

For flat color-keyed sources, `source matte` and animation matting requests can
opt into:

```json
{
  "backgroundScope": "border_connected",
  "edgeColorRecovery": true
}
```

`border_connected` removes only the key-colored region connected to the image
border, protecting enclosed foreground details that happen to match the key.
`edgeColorRecovery` estimates the original RGB of partial-alpha edge pixels
from the key color. Both options remain opt-in; omitted fields keep the previous
behavior. Edge recovery assumes a clean color-key composite and does not replace
visual review.

## Verification

macOS and Windows CI covered Godot 4.3 and 4.2, Windows portable package
installation, resource exchange, and the v0.3 quality matrix. A local real-image
QA run compared the previous magenta-background matting path with the new
options and then verified a padded transparent RGBA lightning sheet through
`preserve_alpha`: all four exported Pack frames decoded pixel-identically to the
source, with zero Provider requests and a valid Pack. See
[the QA record](../qa/chroma-edge-recovery-20260918.md).

This evidence does not approve art quality, licensing, game balance or device
performance. Review assets on their intended backgrounds and in the target game.

## Install and upgrade

macOS Apple Silicon continues to use `forge-installer.sh`. Windows x64 users can
download `forge-windows-installer.zip`, which contains the verified package,
checksum and installer scripts. Existing project locks, receipts and installed
Codex skills are not updated automatically.

Packages are unsigned; the macOS package is not notarized; Windows remains
experimental.
