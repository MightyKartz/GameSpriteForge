# Forge CLI v0.7.7

Forge remains free under MIT; Forge PRO is maintained separately.

Chroma matting now applies `despillStrength` after `edgeColorRecovery` when both
are enabled. Previously the recovery option silently suppressed despill,
including on opaque pixels where recovery does nothing. The existing controls
can still be used independently. Alpha computation, defaults, JSON contracts and
Pack formats are unchanged; reprocessing with both options can change RGB.

Regression tests cover soft edges, opaque spill, alpha preservation and
border-connected exclusions. The [real fox comparison](../qa/chroma-recovery-despill-20261008.md)
separates bright residue from dark fringe: residue stays zero, but fringe remains
and requires visual review. This fix does not promise complete spill removal.

Existing consumer binary pins and installed skills are not automatically
upgraded. Keep the old executable and its matching lock for existing prepared
runs; prepare a new run with a separately verified upgraded toolchain.

The tag workflow must verify paired macOS Apple Silicon and experimental Windows
x64 packages, public launchers, upgrades, bundled helpers and native Godot before
publication. Packages are unsigned; macOS is not notarized. Local source tests
are distinct from versioned package evidence and artistic approval.

## 中文说明

本版修复免费 Forge 抠图中的组合开关缺陷：同时启用 `edgeColorRecovery` 与
`despillStrength` 时，先恢复边缘颜色，再执行去色溢；完全不透明、颜色恢复不处理
的像素也会去色溢。两项处理仍可单独使用。Alpha、默认参数、JSON 合同与 Pack
格式不变；同时启用两项处理并重新准备素材时，RGB 可能改变。

狐狸实测中亮色残留为 0，暗绿描边减少但仍存在，须视觉审阅，不能宣称完全消除。
已有项目锁与已安装 skill 不自动升级；旧 run 继续用原 Forge 与对应锁交付，
验证升级后用新工具链准备新的 run。发布须通过 macOS/Windows 安装包、公共启动器、
升级、随包工具与原生 Godot 验证。Forge 保持免费 MIT 许可，不附模型。
