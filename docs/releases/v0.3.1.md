# Forge CLI v0.3.1

Forge now includes `forge-use`, a Codex skill for preparing game artwork and
delivering it to Godot. Download the CLI and install the skill directly into your
game project; no Forge source checkout or separate skill download is needed.

## Get started with Codex

```bash
forge skill install --project .
forge skill check --project . --json
```

Open that project in Codex and ask it to use `forge-use` to prepare game assets.
For personal installation across projects, use `forge skill install --user`
instead. The bundled instructions cover local PNG preparation, optional Provider
generation and experimental local animation, with self-contained references and
request examples.

`forge skill show` displays the bundled instructions. Its JSON output includes
all bundle files, content hashes and the CLI's compiled identity. Installation
works offline, including when only the Forge executable is available.

## Keep your changes

Skill installation is explicit. Upgrading Forge does not rewrite your installed
skill or a game's toolchain lock. Identical installs are unchanged; updates to
unmodified Forge-managed content retain a backup outside Codex's skill discovery
tree. Modified files, unknown same-name installations and symlink targets are
preserved with a diagnostic.

See the [Codex setup guide](https://github.com/MightyKartz/GameSpriteForge/blob/v0.3.1/docs/automation/codex-skill.md)
for installation scopes, status checks and migration from source-linked skills.

## Install and compatibility

Download `forge-installer.sh` from this release, then run:

```bash
FORGE_VERSION=v0.3.1 sh forge-installer.sh
forge --version
forge doctor --json
```

The regular installer selects the latest stable release and retains older CLI
version directories. `doctor` adds the capability `bundled_forge_use_skill`.
The existing local asset processing and Godot contracts are unchanged.

This release supports **macOS Apple Silicon**. Godot **4.6.x** and Codex image
generation are separate tools; the skill does not install them or provide an
image model. Local PNG preparation needs no Forge Provider account. Character
animation remains in development and testing.

Binaries remain unsigned and not notarized. Release assets include checksums,
build identity, SBOM/attestation and the corresponding bundled FFmpeg source.
