## P2: Decode CLI JSON explicitly as UTF-8

In `.agents/skills/forge-use/examples/local-delivery.py:70-71`,
`subprocess.run(text=True)` uses the Python locale encoding. Forge emits UTF-8
JSON. On a Windows Python installation without UTF-8 mode, non-ASCII executable,
project or artifact paths can be corrupted or fail decoding. The native workflow
sets `PYTHONUTF8=1`, so its current happy-path coverage hides this condition.

Reproduction used the actual rebuilt CLI and shipped script with a synthetic
output directory named `中文`. Only Python's default subprocess decoder was set
to CP1252 to simulate that locale. Preparation succeeded, but retaining the Pack
raised `FileNotFoundError` because its JSON artifact path was decoded as mojibake.
This is a macOS codec simulation, not Windows native acceptance.

Set `encoding="utf-8"` explicitly and cover non-ASCII paths without relying on
the caller's `PYTHONUTF8` setting.

## P2: Bind the request executed to the request checked

The script checks `sourceLocks` at lines 50-52, then passes the mutable original
request path to `plan` at line 122 after doctor and storage probes. A concurrent
request rewrite can remove the locks during that interval. Core deliberately
allows requests without locks, so later Plan fingerprint validation does not
restore this example's stronger requirement.

Reproduction simulated another writer removing `sourceLocks` when the real
doctor call returned. All preparation commands used the real CLI. The claimed
Plan contained no locks, preparation succeeded, and a retained Pack and prepared
receipt were created. The harness deliberately stopped at the installation
command before any project installation. No consumer assets were accessed.

Execute an immutable snapshot of the initially validated request, preserving
request-relative path resolution, and add a regression where the original file
changes during preflight. Merely checking it again before another path-based
read would leave the same race.

stdin. It reads the request once, validates that in-memory snapshot, and sends
the same text through `plan ... --stdin` with the original request directory as
the subprocess working directory. This preserves relative source, lock and
asset-library paths without reading the mutable request again.

The synthetic regression runner now exercises a Chinese output path under a
simulated CP1252 default, rewrites the request during preflight, and checks the
real claimed Plan still contains the original metadata and source locks. A

preparation Job. The full native delivery case now uses a Chinese output path.
