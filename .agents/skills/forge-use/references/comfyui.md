# Local ComfyUI image and video generation

Use this route only when the task explicitly calls for a user-installed local
ComfyUI workflow. All agents use the same Forge commands. Verify the selected
game's Forge executable and the `comfyui_asset_image_create_v1` or
`comfyui_asset_video_create_v1` capability first. Forge does not install
ComfyUI or any model. This build supports one transparent PNG for an
`icon_set`/`prop_set`, and one MP4 for a character animation. Image editing
is not available through `asset create` yet.

1. Export your ComfyUI workflow as **API-format** JSON. Ordinary UI workflow
   JSON with a `nodes` array is rejected. Identify the exact prompt input and
   single output node in the API export. Create a profile following
   `schemas/comfyui-workflow-profile.schema.json`; for installed CLI users,
   `forge provider configure --provider comfyui --profile local --config
   /absolute/profile.json --json` imports it. The CLI stores its hash and rejects
   edits under the same profile ID.
2. Run `forge provider doctor --provider comfyui --profile local --json` while
   ComfyUI is running. Inspect `workflowValid`, `missingNodeTypes`,
   `missingInputs` and `message`. This tests node metadata, not model inference.
3. Copy `forge guide comfyui-image-example` or `forge guide
   comfyui-video-example` to a request JSON, set the explicit
   profile, prompt, `assetId`, purpose, recipe, and optional Godot target. Then
   call `forge asset create --input /absolute/request.json --wait --json`.
   Without `--wait`, generation is queued and the command returns a Job ID.
   Use `forge asset create --resume JOB_ID --wait --json` to poll the same prompt.
   A timeout or disconnected Agent does not submit a second prompt. For H3
   I2V, the profile needs `referenceInput`, the request needs `referenceImage`,
   and the profile's `outputField` must match the actual `/history` response.
   The tested ComfyUI `SaveVideo` node returned MP4 under `images`.
4. Open `previewPath`, inspect `sourcePath` and its `sourceSha256`, plus the
   child `prepareJobId` report and Pack. Technical checks do not approve the
   artwork. Write a review JSON with that exact SHA-256, `approved: true`, and
   reviewer identity. `forge asset create --resume JOB_ID --review
   /absolute/review.json --wait --json` continues installation only if the
   original request already froze `godotProject` and `installTarget`. Inspect
   `installJobId`, its native checks and receipt. A rejected review requires a
   new request for a revised image or video. A video character Pack also needs
   at least one existing `supportAnimations` recipe. Inspect video motion,
   identity and loop endpoints directly; technical `game_ready` is not visual
   approval. `forge asset create --resume JOB_ID --cancel --json` can delete
   only a pending Forge-owned ComfyUI prompt. A running shared-server prompt
   cannot be safely interrupted by Forge.

The same request can use `source` with an absolute, existing transparent PNG
instead of `workflowProfile` and `prompt`. This is useful when the image was
already generated by Codex or another tool. Both routes preserve the source
bytes and use the same static preparation and review steps. The request schema
is `schemas/local-generation-request.schema.json`; review schema is
`schemas/local-generation-review.schema.json`.
For video, `source` may be an absolute existing MP4; Forge retains its audio in
the original source and processes video frames for the character Pack. No audio
asset is installed from that track.

For Codex and a DeepSeek Harness project with skill discovery enabled, install
the managed skill with `forge skill install --project /absolute/game --json` and
verify `forge skill check --project /absolute/game --json`. For Claude Code,
install the same bundle with `forge skill install --project /absolute/game
--agent claude-code --json`, then run `skill check` with the same `--agent`.
Discovery depends on each agent's skill settings; CLI availability alone
does not guarantee that a natural-language request will choose Forge.
